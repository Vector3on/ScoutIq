# GEO decisions

1. **Protect the branches.** Create one new ref from the recorded master SHA; write a single-parent commit there. Import source trees/files by Git object identity, never merge or edit the source refs. Recheck original refs after publishing; concurrent third-party changes must be reported, not undone.
2. **Reuse v4 unchanged.** Import the full Loam substrate so its core and tests remain coherent. Add only a domain plugin and runner. Do not silently port or rewrite the planner.
3. **Measure consumer surfaces directly when available.** Search-engine snippets, API answers and this assistant's invented example are not substitutes for “ChatGPT said X.” Actual browser snapshots are retained. Perplexity's access block is separate from a failed query, since no query was sent.
4. **Sell a scoped pilot audit first.** The deliverable is a transparent baseline and investigation queue, not a promised visibility lift. Five real answers make a working slice; they are insufficient for a commercial population claim. The brand choice after the first answer is disclosed.
5. **Keep missingness.** Every unknown remains null. Blocked responses never become negative visibility. Visible source drawers are explicitly incomplete. Source authority remains unassessed until independent evidence supports a judgment.
6. **Use binary appearances.** Repeated brand names cannot inflate visibility or voice. Aliases and the tracked competitor set are explicit configuration. Brand-link rates and prose mentions are separate measurements.
7. **Separate measurement from judgment.** Intent, fixability and opportunity are priors/model outputs; sentiment requires a quoted analyst annotation. Marketing actions are untested hypotheses. Hash validation prevents accidental changes, not forged human provenance.
8. **One metrics implementation.** The plugin consumes Python results, and the exact same Python file is frozen. Melt validates the pure score function and records zero-model-call receipts; IO is not falsely described as sandboxed.
9. **Preserve sampling conditions.** No pooling across engine, model, locale, session, search mode or citation coverage. Fresh tabs in one anonymous browser do not establish independent users. Wilson intervals carry that caveat. Adaptive prompts cannot be silently included in fixed-battery trend estimates.
10. **Novelty searches ways to investigate.** Loam's real archive evolves graph-query strategies. It does not magically prove marketing strategy effectiveness. Frame contrasts and competitor-publisher dependence are concrete hypotheses; intervention learning needs real outcomes.
11. **No fragile consumer bot client.** A reusable manual collector works with consumer accounts without paid APIs. Optional Gemini API use requires explicit free-tier configuration and is separately labelled. No cookie extraction, CAPTCHA evasion, fingerprint tricks or paid fallback.
12. **Keep $0 claims conditional.** Offline replay costs no API usage. Free-tier access is conditional on provider quotas and billing-disabled configuration, which cannot be verified from a key alone. No accounts, keys, billing or scheduled paid services were created.
13. **Retain evidence privately by default for future clients.** The included pilot contains public brand queries and anonymous answers only. Real client captures may be sensitive: do not commit them to a public branch. The reusable collector is local, and its output directory is ignored.
14. **Use GitHub APIs when cloning is unavailable.** Local shell GitHub cloning was blocked; the installed GitHub connector can fetch and write Git trees. The new commit retains master's parent and all master tree entries. Local work is a materialized source workspace, not a claim that a shell git push succeeded.
